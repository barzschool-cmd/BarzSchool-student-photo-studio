GitHub & Hosting Deployment Guide

This application is structured as a zero-build, self-contained single-page web app ready to run directly on GitHub Pages, Vercel, or Netlify.

1. Deploying to GitHub Pages

  1. Create a new repository on GitHub (e.g., student-photo-app).
  2. Commit this index.html file as the repository root.
  3. Go to Settings → Pages.
  4. Under Source, select main branch and click Save.
  5. Your app will be live at https://yourusername.github.io/student-photo-app/.

2. Data Persistence & Real-time Sync

The app runs automatically with internal persistent state storage. Changes are synchronized across sessions and survive page refreshes smoothly.
